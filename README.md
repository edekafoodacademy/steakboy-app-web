# Steakboy App

Installierbare Web-App der EDEKA Food Academy Fresh für Mitarbeitende hinter der Bedientheke.

**Adresse:** https://edekafoodacademy.github.io/steakboy-app-web/

Dieses Repo enthält nur die fertig gebaute App (Zweig `gh-pages`), keinen Quellcode und kein Rohmaterial.
Quellcode, Wissensbasis und Unterlagen liegen im privaten Repo `edekafoodacademy/steakboy-app`.

Die App enthält nur Wissensthemen, die fachlich freigegeben sind. Aktualisiert wird sie aus dem privaten Repo.
